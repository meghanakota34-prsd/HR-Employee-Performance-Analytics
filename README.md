# HR Employee Performance Analytics Dashboard

## Project Overview

This project presents an interactive HR Employee Performance Analytics Dashboard developed using Microsoft Power BI. It helps analyze employee performance, attendance, promotions, attrition, and workforce distribution.

## Project Objective

To analyze employee performance, monitor attendance, evaluate promotion status, identify attrition patterns, and generate meaningful HR insights to support data-driven decision-making.

## Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Cleaning
* Data Visualization

## Dataset Overview

The dataset includes employee information such as:

* Employee ID
* Department
* Gender
* City
* Job Role
* Work Mode
* Attendance
* Performance
* Training Hours
* Promotion Status
* Attrition Status

## Key Performance Indicators (KPIs)

* Total Employees: 999
* Average Attendance: 91.16
* Average Performance: 2.68

## Dashboard Analysis

1. Employee Count by Department
2. Average Performance by Department
3. Average Performance by Job Role
4. Training Hours by Performance
5. Employee Promotion Status
6. Employee Attrition Status

## Interactive Filters

* Gender Filter
* Work Mode Filter
* Department Filter
* City Filter
* Job Role Filter

## Key Insights

* Analyzed employee distribution across departments.
* Compared performance across different departments and job roles.
* Explored the relationship between training hours and employee performance.
* Evaluated employee promotion status.
* Analyzed employee attrition patterns.

## Business Value

This dashboard helps HR teams understand workforce performance, identify employee trends, monitor attrition, and make informed HR decisions.

## Project Details

* Project Type: Self-Initiated
* Domain: HR Analytics
* Tool: Power BI
